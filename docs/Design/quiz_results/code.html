What is the primary purpose of Azure Resource Locks?

close To encrypt sensitive data at rest
Your Answer
check To prevent accidental deletion or modification
Correct Answer
info

Resource locks help you prevent accidental deletion or modification of your Azure resources. They are not used for encryption (which is handled by Azure Key Vault or built-in service encryption).
